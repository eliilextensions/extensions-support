# Browser Extensions

Four small, privacy-friendly extensions for Firefox and Chrome.
They have no tracking and no servers, and all data stays in your browser.

| Extension | What it does | Firefox | Chrome |
|---|---|---|---|
| **TGM TabGroupManager** | Manage all your tab groups in one place | [Get it](#) | [Get it](#) |
| **TB_TabSleep** | Put unused tabs to sleep and save memory | [Get it](#) | [Get it](#) |
| **STH_SiteTimeHistory** | Track and limit your time on websites | [Get it](#) | [Get it](#) |
| **PM_PageMemo** | Highlight and take notes on any web page | [Get it](#) | [Get it](#) |

All four are available in English, 日本語, 中文 and 한국어.

---

## TGM TabGroupManager

See, organize and restore all your tab groups from the sidebar (Firefox) or side panel (Chrome).

- Pin groups so they come back after a restart
- Save and restore groups
- Workspaces
- Drag & drop for groups and tabs
- Auto-grouping rules
- Auto-collapse
- Find duplicates and old tabs
- Group notes
- Backup
- Sync

## TB_TabSleep

Sleeps tabs you aren't using so the browser uses less memory. Sleeping tabs wake up when you click them.

- Sleep right away, or after 5 sec to 8 hours
- Memory-saved stats and a 7-day chart
- Startup savings summary
- Faster sleep when many tabs are open
- Presentation mode
- Exceptions for sites, groups, pinned tabs and tabs playing sound

## STH_SiteTimeHistory

Shows where your time goes and helps you cut back on distracting sites.

- Time per site
- 30-day history
- Focus score
- Daily goal and streak
- Site limits with schedules
- Block page
- Strict mode
- Weekly report
- CSV export

## PM_PageMemo

Highlight text, add notes and place sticky notes on any page. They come back when you return to the page.

- 4 highlight colors
- Notes shown on hover or click
- Draggable sticky notes with text formatting
- Page memo
- Right-click menu and shortcuts
- Search all notes and filter by #tags
- Markdown and JSON export
- Light and dark theme

---

## Sync

Each extension can sync through your own browser account:

- **Firefox:** Firefox Sync, using your Mozilla account
- **Chrome:** Chrome sync, using your Google account

Nothing is stored on any other server.

## Privacy Policy

These extensions do not collect, transmit, sell or share any personal data.

- All data is stored only in your browser using the browser's storage. This includes settings, tab groups, usage time, highlights and notes.
- If you turn on sync, your data is stored in your own browser account through the browser's built-in sync. The developer has no access to it.
- No analytics, tracking, advertising or remote code is used.
- You can delete all data at any time by removing the extension or using the reset option in its settings.
